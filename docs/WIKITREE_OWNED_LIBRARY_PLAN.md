## 核心目標

WikiTree 不再把「目前打開的 Windows 資料夾」當成產品本體。桌面版啟動後會自動進入由 WikiTree 管理的本機筆記天地；使用者可以在裡面建立自己的資料夾與筆記，也能把外部文件或資料夾複製收進來。原始文件保留，匯入後的 WikiTree 版本獨立成長。

## 已確認的產品決定

- 保存方式：WikiTree 自動管理。
- 預設位置：使用者的「文件／WikiTree」。
- 匯入方式：複製進 WikiTree，保留外部原檔，不做暗中同步。
- 日常入口：開啟 WikiTree 便進入「我的 WikiTree」，不要求先選擇資料夾。
- 外部資料夾：只作為匯入來源，不再是主要工作區。
- 檔案格式：繼續保存為可攜、可備份的本機 Markdown，而不是鎖在不透明資料庫。

## 第一版完成定義

1. 使用桌面版時，不必挑選 Windows 資料夾便能新增與閱讀筆記。
2. WikiTree 內可自行建立資料夾與筆記。
3. 外部 Markdown、純文字文件或整個資料夾能先預覽，再複製收進 WikiTree。
4. 匯入不覆蓋既有內容、不刪除原檔，也不建立看不見的雙向同步。
5. 既有筆記編輯、歷史、發布、AI、探索苗圃與風格入口仍能完成靜態編譯。

## 第一版之外

- 跨裝置雲端同步。
- 多人共同編輯。
- 公開個人封面與苗圃裝飾。
- 外部原檔與 WikiTree 文件的雙向同步。
- 將歷史版本與引用關係從路徑進一步升級為永久葉片身分。
