# HTML 講義閱讀

WikiTree 可以直接閱讀 `.html` 和 `.htm` 講義，保留原有樣式、折疊問題、頁內目錄與一般頁內 JavaScript 互動。點開 HTML 不會建立 Markdown、不會改寫原檔，也不會送進 Markdown 編輯器。

## 本機試用

1. 點原本桌面的 WikiTree 捷徑，開啟日常版本（`http://localhost:5173/`）。HTML 閱讀功能已接入主版本；如果舊視窗還開著，請關閉舊視窗後重開原捷徑，再重新選擇要收進的文件或資料夾。
2. 點「收進 WikiTree」→「選擇文件」，選擇 HTML 講義。若講義另外附有圖片、CSS 或 JavaScript，請選「選擇資料夾」，帶入整包內容。
3. 確認預覽與目的地後收進。HTML 及附件會放入新的獨立資料夾，重複收進會加編號，避免覆蓋或打亂附件連結。外部原檔會保留。
4. 在左側展開講義資料夾，點 HTML，試讀原有排版、目錄、折疊與互動。附件會標示「附件」，不能誤當成筆記編輯。
5. 需要文字編輯時才點「轉成 Markdown 副本」。確認後保留 HTML 並開啟新的 Markdown；副本無法完整保留原有樣式或互動。
6. 講義裡若有「世界的門」之類的原有 HTML 連結，例如 `<a class="door" href="下一個世界/講義.html">進入世界</a>`，點擊會直接開啟那份講義，原按鈕樣式會保留。兩個入口開啟同一個檔案，不會再建立副本。
7. 左側頂部的收起按鈕可隱藏清單，閱讀時專注於講義；左上角的展開按鈕可找回清單。收起不會刪除任何資料夾或筆記。

首次取得程式碼時先執行 `npm.cmd ci`；本機資料仍放在自己的「文件／WikiTree」。原捷徑會啟動桌面專案資料夾目前的版本，並嘗試拉取目前分支的更新；其他分支的新提交不會自動接入。遇到離線或同步失敗會繼續使用本機版本。

額外的 `try-html.bat`／`npm.cmd run try:html` 仍可用於隔離試用（5174／18180），日常桌面入口則使用 5173／18080；兩邊共用筆記，請避免同時編輯同一份文件。

## 匯入目的地（2026-10-02 修正）

選「我的 WikiTree（最外層）」時，筆記會收進最外層；HTML 講義及附件仍會放入獨立講義資料夾，但這個資料夾會直接位於最外層。未提供目的地時，仍預設「收件苗圃」。同名內容會加編號，不覆蓋已有筆記；先前已收進苗圃的內容不會自動搬動。

本機確認方式：先關閉既有 WikiTree 視窗與啟動服務，再用原本桌面捷徑重開。點「收進 WikiTree」，選一份測試文件，將「收進哪裡？」改為「我的 WikiTree（最外層）」後確認。一般筆記應直接出現在左側最外層；HTML 講義應出現在最外層的新講義資料夾中。可再選一次「收件苗圃」確認指定目的地仍正常。

`npm.cmd run check:library` 另以測試暫存資料檢查最外層筆記、資料夾、HTML 與二進位附件、重複匯入及未指定目的地的預設行為，不操作使用者筆記。

## 支援與限制

### Markdown 與 HTML 的風格（2026-10-02）

- Orbit 的「風格」頁面先選 Markdown 或 HTML，再顯示該類風格。
- Markdown 保留原本七種風格，預設 WikiTree Original；你選的風格仍保存在這台裝置，筆記與工作介面照原有方式套用。
- HTML 只有「自適應」，開啟講義即自動生效。側欄、頂部列及閱讀外圍會跟隨講義的主要背景、文字與代表色；講義原有排版、顏色及互動不改寫。
- 配色參考目前可見區域的大面積背景與醒目元素，會在講義載入完成、視窗大小或講義自己的配色切換時重新讀取。讀不到顏色、圖片或漸層底色時使用穩定的暖白配色；外圍文字與操作色會調整為易讀的對比。
- 切回 Markdown 筆記或離開 HTML 閱讀畫面，會恢復所選的 Markdown 風格。不同講義的配色不會覆蓋這個選擇，也不會修改已有筆記。
- 暖度、紙感、裝飾感與強度仍屬後續概念討論，本版沒有這些控制。

本機試用：用原桌面 WikiTree 捷徑重開，進入 Orbit →「風格」，確認 Markdown 有七種風格、HTML 只有自適應。先選一種 Markdown 風格，開啟暖白／青綠或另一種配色的 HTML 講義，查看外圍是否跟隨講義；再切回 Markdown 筆記，確認恢復原先選擇。讀不到配色的講義會先使用暖白外框。若仍顯示舊版，可重新整理 WikiTree 視窗。

`npm.cmd run check:html-theme` 以合成配色與區域大小、靜態 HTML 和伺服端輸出檢查配色發現、訊息來源保護、外圍套用、暖白回退、七種 Markdown 風格復原與兩類風格清單。沒有開啟瀏覽器，沒有執行講義原有程式，沒有操作使用者筆記；這些結果不代表實際外觀或使用感受已驗收。

本次 `check:html-theme`、`check:themes`、`check:html`、`check:library`、`check:launcher` 與 `build` 通過；變更的配色工具、HTML 閱讀工具與兩個相關介面元件通過程式規範檢查。建置後執行 `npm.cmd run check:html-theme -- --built` 亦通過，確認壓縮後的配色程式仍可獨立執行。建置另有既有大型輸出檔提示，未阻止完成。

### 講義支援範圍

- 原有內嵌樣式與一般內嵌程式可閱讀；本機 CSS、JS、圖片、字型、音訊和影片可讀取，CSS 的相對圖片與 `@import` 也會處理。使用 UTF-8 講義。
- 附件僅能來自目前 WikiTree 內的非隱藏路徑。一次收進最多 500 個檔案、總共 15 MB；單一可讀附件上限 20 MB。缺少或不支援的附件會列在閱讀畫面。
- HTTPS 外部圖片、字型與程式仍需要網路。HTTPS 嵌入影片還取決於來源網站是否允許嵌入與隔離頁面；未驗證所有網站。
- 講義的程式沒有 WikiTree 筆記權限，也不能讀取 WikiTree 的登入資訊。它不能發送資料請求、提交表單、使用持久儲存或控制整個 WikiTree 視窗。閱讀中的暫時互動狀態在重開時會重置。
- 依賴 `fetch`、外部登入、`localStorage`、ES module 相對匯入、程式動態建立的相對附件、Worker 或本機巢狀 HTML 嵌入的講義，可能需要另作適配。本次沒有完整 HTML 編輯器。
- 頁內 `#章節` 可跳轉；另一份已收進的相對 HTML 連結可切換閱讀。跨講義連結中的章節位置目前不會保留。外部來源連結會另開分頁。
- 「發送訊號」仍使用 Markdown 發布流程；HTML 閱讀時不開放這個操作。AI 可以參考講義，但插入、附加或修整文字須先建立 Markdown 副本。
- 演化紀錄保存文字筆記（包含 HTML），不保存或還原圖片、CSS、JS 等附件。請自行備份整包講義；還原舊紀錄時附件會留在原位。

## 靜態驗證

`npm.cmd run check:html` 檢查 HTML 原檔保留、重複收進、二進位圖片、相對資源、CSS 匯入、隔離請求阻擋、路徑與資料夾連結邊界、改名格式與歷史保護。HTML 只由靜態解析器讀取，不會執行講義程式。

其他檢查：`npm.cmd run check:library`、`node scripts/check-markdown.mjs`、`node scripts/check-workspaces.mjs`、`npm.cmd run check:launcher`、`npm.cmd run build`、`node --check cli-server.cjs`、`git diff --check`。

未進行瀏覽器或電腦介面測試。這些結果不代表已驗收實際外觀、折疊操作、影片播放或互動程式；實際閱讀感受留給使用者本機試用。
