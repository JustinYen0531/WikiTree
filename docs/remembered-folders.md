# 桌面版資料夾記憶

- 在左側「FOREST」按「加入資料夾」，選擇本機資料夾。可重複加入不同位置；相同路徑不會重複列出。
- 新加入與重新啟動後的資料夾預設收合。按箭頭展開／收合，按名稱切換目前資料夾；不同資料夾可同時展開。
- 下次啟動保留清單，自動接回最後使用的資料夾。重新加入已移動的資料夾即可修正失效路徑，不會自動重建舊位置。
- 資料夾右側的 × 只從清單移除，不會刪除電腦上的資料夾。關閉全部後，下次也不會重新出現。
- 切換或關閉目前資料夾時，如果筆記未儲存，會先詢問。取消即可留在原筆記。
- 檔案儲存、歷史版本、發布和 AI 請求各自帶上所屬資料夾，不受另一個資料夾同名檔案影響。

記憶保存在這台電腦的應用程式儲存空間。清除網站資料、換瀏覽器使用者或改用其他本機網址後需重新加入。未連接桌面服務的瀏覽器模式，原生選擇器資料夾只保留當次工作階段。

更新後須重新啟動桌面服務。舊服務無多資料夾支援時，會提示重新啟動，避免把操作送到錯誤的資料夾。

驗證：`node scripts/check-workspaces.mjs`、`node scripts/check-markdown.mjs`、`node --check cli-server.cjs`、`npm run build`、`git diff --check`。使用記憶體模擬資料夾與伺服器、靜態產生左側標記，不開啟瀏覽器、不讀寫使用者的筆記。
