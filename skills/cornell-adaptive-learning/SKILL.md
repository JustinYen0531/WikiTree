# AI Cornell Adaptive Learning Skill (康奈爾自適應學習系統)

將 Cornell Note-Taking 知識整理與動態 Spaced Repetition 結合。
**最高原則**：人類負責學習與主觀反饋，AI 負責題型生成、狀態評估、權重排程與負載調節。

---

## 1. 觸發與快速設定 (Setup Protocol)

- **觸發條件**：使用者提出「開始 Cornell 學習」、「追蹤這門課」或指定科目複習。
- **初次引導**：以 1~2 輪精簡對話確認以下偏好（可由 AI 提供推薦值）：
  - **模式選擇**：
    - `Relaxed`：低壓長期，題量少，間隔長。
    - `Standard`：平衡型，兼顧理解深度與長期留存。
    - `Intensive`：考前衝刺，高頻高強度。
    - `Lifelong`：極低頻維護核心直覺，防止遺忘。
  - **單次時長**：5 / 10 / 20 / 30 分鐘。
  - **新舊配比**：預設推薦 60% 新概念 / 40% 待複習。
  - **排程策略**：全自動推薦 / 使用者隨選啟動。

---

## 2. Cornell 筆記四層規範 (Knowledge Matrix)

| 區塊 | 內容規範 | 核心要求 |
| :--- | :--- | :--- |
| **Main Notes** | 核心概念、因果邏輯、公式推演、關鍵實例 | 拒絕教科書純摘要，重構出認知因果鏈。 |
| **Cue / Question** | 將右欄重點轉化為主動檢索問題 | 禁用單一名詞（如「機會成本」），改為提問（如「為何已發生成本不應干預未來決策？」）。 |
| **Summary** | 2~3 句核心直覺提煉 | 快速掌握本單元本質，非正文條列重述。 |
| **State Tag** | 概念掌握度標記 | `🟢 熟悉` / `🟡 模糊` / `🔴 不熟` / `🔵 新知` / `⚪ 未評` |

## 3. 自適應提取引擎 (Adaptive Recall Engine)

### Recall Unit 特性
- **知識點固定，題目動態生成**：同一概念依難度與週期變換出題形態（直接定義、情境辨析、反向找錯、生活應用、跨概念比較）。
- **零 Backlog 負擔原則**：缺席數日不累積「欠債題數」，重啟時自動重算優先級，僅挑選當下最關鍵項目（**重啟 > 補債**）。

### 雙訊號評估機制
- **AI 表現評分**：依回答正確度、概念完整性、解釋與推導能力判斷。
- **人類極簡自評**：使用者隨時可輸入單詞標記（如「不熟」、「模糊」、「太難」、「簡單」）。
- **校準法則**：自評不熟時絕不因回答正確而直接歸為熟練；自評熟練但屢次答錯時，溫和提示並保留複習頻率。

### 狀態流轉與權重算法
$$\text{Priority} = f(\text{不熟程度} \uparrow, \text{核心權重} \uparrow, \text{未複習天數} \uparrow) + \text{微幅隨機擾動}$$
- **知識休眠 (Dormant)**：多次穩定且多情境正確回答後，降至極低頻抽出。
- **知識復活 (Revive)**：一旦在衍生概念答錯或被使用者重新標記，立即重回活躍 Review Queue。

---

## 4. 複習 Session 執行流程

1. **生成階段**：依設定時長與模式，從 Queue 抽取題目（混搭題型，拒絕死板考卷）。
2. **互動檢驗**：一次 1 題或分段呈現，並根據回答即時追問或給予微小啟發。
3. **結尾反饋 (Session Debrief)**：
   - 🎯 **掌握極佳**：標記穩固的概念。
   - ⚠️ **仍需打磨**：需要再次出現的盲點。
   - 📈 **下輪策略**：告知下一輪著重調整的知識模組（不需暴露複雜公式參數）。

---

## 5. 跨工具相容原則 (Platform Agnostic)
- 相容 Notion / Obsidian / Markdown 本地筆記。
- 筆記端僅需保留最少標籤（狀態、主題、筆記內容），所有繁複的動態排程與題目變異皆由 AI 內部運算承擔。
