# Humanized Lifelong Learning Notes Protocol

目標：將教材轉化為建立直覺與決策力的「終身思維工具書」，非應考清單。

## 1. 寫作原則與約束
- **語調**：真誠對話、富作者感，兼顧學術嚴謹與現實溫度；嚴禁應試字眼（必考/背誦/考點）與空泛心靈雞湯。
- **案例分級**：
  - `Illustrative`（假想）：標明為理解模型。
  - `Real-world`（真實）：嚴禁捏造事實、數據或人物，需有所本。
- **純工具處理**：無哲學意涵的純技術內容，如實講述用法，切忌強行昇華。

## 2. 知識單元輸出規範 (8 步順序)
1. **概念直覺**：素人白話起手，先建立物理/生活直覺，禁首句塞定義。
2. **存在理由**：為了解決人類何種痛點、混亂或認知盲區而發明。
3. **正式概念 (三層法)**：
   - 層一（直覺）：公式本質在衡量/平衡什麼。
   - 層二（符號）：正式定義、符號與精準數學式。
   - 層三（動態翻譯）：變數 $\Delta$ 在現實世界對應的具體意義。
4. **生活映射 (2~4 視角)**：日常微觀 / 人生與職涯決策 / 商業與體制 / (跨界遊戲科技)。
5. **作者碎碎念**：2~4 句個性化旁白，點出常見誤區或個人洞察。
6. **真實邊界**：課本沒教的假設漏洞、失效場景、人性與制度落差。
7. **思考轉化**：將概念提煉為 1 個面對現實時的「習慣性反思提問」。
8. **帶走一句話**：簡短、深刻且不矯情的核心收尾語。

## 3. 章節結尾規範
- **三年後只記三件事**：抽離公式仍終身受用的 3 大思維核心。
- **生活觸發情境**：3~5 個未來會突然聯想到該概念的現實場景。
- **留給未來的自己**：2~3 個無標準答案的人生意涵問題。

## 4. 驗收核檢
- [ ] 讀者不為考試也主動想讀？
- [ ] 抽掉公式後仍留存心智模型？
- [ ] 具備真實世界觸發點與反射提問？
- [ ] 5 年後重新翻閱依然具有啟發性？
