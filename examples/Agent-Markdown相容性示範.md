# Agent 筆記格式相容性示範

這份筆記刻意保留 Agent 常見的空格與中文標點。請在編輯模式、分割預覽，以及 Agent 插入預覽中比較；粗體應顯示文字，而不是露出星號。

## 🌱 根節點：什麼是機器學習？

- **一句話定義**：不是工程師手寫死規則，而是給予大量數據與目標，讓演算法**「自己找出輸入與輸出之間的對應公式（權重）」 **。
- ** 概念 **：每筆資料都有標籤（Label / Ground Truth）。
- **分類（Classification） **：二分法或多元判斷。
- **回歸（Regression） **：預測連續數值。
- **主要任務**：只有**環境（Environment） **、**動作（Action） **與**獎懲分數（Reward） **。

## 不同位置都能呈現

1. **監督式學習 **：利用有標籤的資料學習。
2. **非監督式學習 **：探索資料中的結構。

> 中文**「重點」**接續文字也應正常呈現。

> [!TIP] ** 學習提示 **
> **分類 **與**回歸 **是不同任務。
